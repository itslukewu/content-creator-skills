# content-creator-skill

Claude skills for content creation.

## Skills

| Skill | What it does |
|---|---|
| [`lukes-copywriting`](lukes-copywriting/SKILL.md) | Plans and refines content copy with academic research methods: narrow a topic into a question, scan competitors for gaps, distill a thesis, build the hook and structure, list evidence, state limitations. |
| [`topic-finder`](skills/topic-finder/SKILL.md) | Finds content topics: infers an initial audience from benchmark accounts' outperforming posts, searches per pillar and across benchmark posts, market signals, and saved references, then outputs a topic table with source links and readiness. English version for English-speaking users; Chinese version ([`zh-CN`](skills/topic-finder/zh-CN/SKILL.md)) for Chinese-speaking users. |

## Using a skill

Each skill is a folder with a `SKILL.md`. To use one in Claude, upload the folder as a skill, or copy it into `~/.claude/skills/` for Claude Code.
